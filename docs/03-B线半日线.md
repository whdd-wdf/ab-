# 03 B 线半日线

来源技能：`local-stock-sniper`（AlphaSniper 选股）+ `local-uzi-astock` 看门狗（uzi_gate.py）。本章是执行口径的整理版。

## 核心逻辑（2026-10-26 用户确认，纠正此前口误称 A 线）

- 大盘安全情况下，优选上涨趋势成立、基本面安全的股票。
- 买入后若趋势没有了，买入逻辑就不成立，考虑脱手，否则会被套。
- 每天筛选逻辑成立的股票补充 B 线是必要的——14:30 尾盘选股即为此。
- 交易原则：**买要考虑周全，卖要干脆**。

## 仓位与上限

- B 线初始额度 500,000 元；每次卖出已实现盈亏计入额度（盈利加、亏损减）。
- 单只金额 ≤ 100,000 元；同时持仓 ≤ 3 只；不碰 510300，不动 A 线底仓。
- 买入时持仓成本 + 本次买入金额不得超当前动态额度；额度由额度脚本统一计算。

## 14:30 尾盘选股（AlphaSniper 6 阶段）

1. 市场健康检查：指数涨跌幅、涨跌家数必须用当日实时行情；恐慌门触发则空仓，不硬凑。
2. 板块热点：找当日机构资金流向强的板块。
3. 候选池：从热点板块提取候选股。
4. 量化打分：硬过滤 + 四维打分；数据缺口明确标注、降级处理，绝不编造。
5. AI 对抗验证：风险视角挑战每只候选，结论为 APPROVE / RISKY / REJECT。
6. 最终输出：≤ 3 只推荐，每只附操作策略；无符合标准股票时如实告知空仓。
- 选股偏好：尾盘形态已明朗、当日趋势向上的标的（尾盘放量上攻、突破日高、回踩分时均线企稳等）；推荐逻辑是今日尾盘买入，不是次日开盘。
- 数据铁律：所有代码、名称、价格、涨跌幅必须来自本次运行的实际结果（数据源优先级：东方财富 → 新浪）；新闻/快讯须核验日期确为当天；拿不到就标注，不用旧数据充数。
- 推荐先发：看门狗复核一结束，立刻先发推荐给用户（收盘前用户需要看到才有时间跟单），不要等买完再发；买入执行随后另行确认。

## UZI 看门狗（有候选股时才跑，约 3–5 分钟）

并行跑三项硬伤检查，输出 ✅ 通过 / ⚠️ 警告通过 / ❌ 否决：

1. DCF 估值：内在价值 < 市值 70% 直接否决。
2. 龙虎榜：机构砸盘 / 游资恶炒。
3. 杀猪盘 8 信号扫描。

- ❌ 否决的候选直接剔除；⚠️ 警告通过的如实告知风险点；全部否决则按空仓处理。
- 看门狗跑失败时降级为人工三点核验（估值 / 龙虎榜 / 杀猪盘，经当日数据），并在报告中注明“看门狗故障，人工核验”。
- 完整 UZI pipeline（66 评委）跑完需 30 分钟以上，赶不上尾盘窗口，仅作盘后离线深挖。

## 早盘卖出（09:20）

- 先查隔夜消息：若发现实质利空（如隔夜不利消息），T+1 开盘直接全卖。
- 无实质利空，再按分批止盈 / 止损规则执行。
- 卖出目标（按成本口径）：+3% 卖一半、+5% 卖剩余；止损：-3% 卖一半、-5% 卖全部。
- 早盘任务的成本公式历史遗留问题见 [07 风险与待办](07-风险与待办.md)（平均成本口径，未改 FIFO）。

## 盘中止损监盘（2026-10-22 起，只做止损侧）

- 止盈仍只走早盘；盘中监盘只做止损侧。
- 规则：先判 -5%；-3% 卖当前剩余持仓一半、-5% 卖当前剩余持仓全部。
- 确认口径：当日 5 分钟 K 已收盘 bar 的收盘价穿线（bar 时间戳 + 6 分钟 ≤ 现在）才触发；同日同档一次、次日重置。
- 触发才开桌面版 1 窗下单，成交第一时间通知；失败满 3 次报“需手动处理”，绝不编造成交；取数失败不触发。
- 标的（2026-10-26 起）：600176、002475、000596（000596 为 2026-10-26 用户批准补进）。
- 002475 是 T+0 影子底仓，盘中卖出须注明底仓变化，不得擅自改哨兵参数。
- 注意：个别任务文件正文仍写着已过期的“盘中不监盘”，报告与执行一律按本节新口径，改文件正文须走完整读取与确认流程。

## 止损回补研究（进行中，未入策略）

- 立项：B 线盘中止损卖出后，若尾盘复核原买入逻辑仍成立，是否应把卖出的仓位补回。
- 采纳门槛：样本 ≥ 10 例且胜率 > 70% 才提请加入；10 例的 70% 统计上并不稳固，只是门槛，不是证明。
- 评估要点：① 无实质利空；② 原逻辑核心事实未变（新仓视角）；③ 技术企稳；④ 原“回补价不高于卖出价”一条已废止（属卖出价锚定，与买入决策规则冲突）；⑤ 当日 -5% 已触发则不补（前置否决）。
- 回补量固定为当日止损卖出量（仅为测试样本固定量，非决策理由），只补一次。
- 案例进展见 [07 风险与待办](07-风险与待办.md)。
