# A线建仓（首笔建仓）

建仓是 A 线网格的起点：第一天按账本把底仓买进来，之后才有股票可卖、有现金可补。本 skill 规定**首笔买多少、怎么买、买在哪**，执行口径以总纲 docs/01 第 1 章为准；规则冲突时以总纲为准，原则冲突时以本 skill 所载用户亲定为准。

## 核心原则（用户亲定，按时间顺序）

### 1. 涨有股票是建仓的基本前提（2026-11-14 22:36、22:52 定）

- **建仓阶段没有“跌有钞票”的问题**：建仓时现金本来就预留 60%~85%，不怕跌；唯一的前提是**手里必须有股票**，涨了才有东西可卖。
- **Day 1 必须有底仓**：建仓第一天，三个股票（或全部建仓标的）都要买入底仓，**底仓不能为零**。
- **高位也不例外**：哪怕市价在历史高位，也必须持仓，解决办法是**适当减少持仓数量**，不是空仓等待。

### 2. 首笔数量按历史分位定（2026-11-14 22:44 定）

- **分位** = (现价 - 历史最低点) / (历史最高点 - 历史最低点)，历史取**一定期限内（52 周）且除权**（前复权）的高低点。
- **首笔比例** = 40% - 25% × 分位（底部 40%，顶部 15%）。低位多、高位少，线性。
- 分位示例（2026-11-13 收盘）：
  - 601398：分位 98.7% → 首笔 15.3%（27 手）。
  - 600900：分位 96.6% → 首笔 15.8%（8 手）。
  - 601857：分位 70.4% → 首笔 22.4%（25 手）。
- **“一板 5 手”口径已作废**（用户 2026-11-14 22:44）：5 手是历史最高点才会出现的情况，现在根本不可能；不要拿“一板可卖 5 手”当硬门槛，改按分位定仓。分位高时一板可卖不足 5 手是合理结果，不是错误。

### 3. Day 1 市价买入，不挂单等回调（2026-11-14 22:36 定）

- **错误做法（v2 教训）**：首笔全靠挂买单等回调，市价上涨时买单不成交，Day 1 零持仓，涨了没股票可卖。
- **正确做法**：Day 1 开盘即按账本分布**市价买入**底仓，股数按账本节点分配，买入价 = 开盘价（市价）。
- 左侧交易不怕跌：市价买入后若下跌，账本下方节点有买单可补仓（现金预留 60%~85%），不怕跌。
- **跌就见机建仓（2026-11-14 22:56 定）**：跌不是风险，是建仓机会；市价跌到下方节点价，见机买入补仓（按账本节点价挂买单，触及即成交）。跌得越深，买得越多（金字塔：越往下越多），但须留足现金、不超额度。

### 4. 区间按真实数据定（2026-11-14 定）

- 网格区间按**52 周高低点**定：网格顶 = 52 周高 × 1.10（历史高点上提 10%），网格底 = 52 周低附近（取整）。
- **绝不能用脱节的旧区间**：海王星原方案 601398 [3.50, 6.50]、601857 [4.50, 8.50] 与市价（8.85、12.39）严重脱节，5 日回测 0 成交，已作废。重建前必须核对市价是否在区间内。
- 锚取区间中点附近的整数，lattice 每档 1.02 倍链式取整。

### 5. 仓位布局：按现价在箱体的位置定应该持仓量（2026-11-15 定）

- **原则**：多周转才能多赚。仓位不是固定不变的，要按现价在一年区间（箱体）里的位置动态确定。
- **方法**：全额 quota 按金字塔分配到全部节点（下方节点多配、上方少配）；现价上方节点股数之和 = 应该持仓量；现价下方节点金额之和 = 应该留的现金。
- **调仓**：现持仓与应该持仓不一致时，多了抛、少了买，与确定一致。浮亏小时调仓正合适（不锁定大亏损）。
- **一板覆盖（用户 2026-11-15 16:04 重申）**：任何时候都要有往上布一个板（+10%）的股票，哪怕每个节点就一手。高位每节点股数可以减少，但节点必须布到。窗口内每节点至少 1 手是底线，目标持仓不得低于窗口节点数 × 100 股。
- **案例（2026-11-15，系统1 A线）**：
  - A1（510300，分位 5.3% 低位）：应该持仓 29,100 股，现持 30,800 股，卖出 1,700 股。
  - A2（601088，分位 86.3% 高位）：应该持仓 500 股（窗口 5 档各 1 手底线，原算 200 股已修正），现持 1,200 股，卖出 700 股。
  - A3（513650，分位 81.5% 高位）：应该持仓 11,400 股，现持 33,000 股，卖出 21,600 股。
- **调仓后**：持仓与账本一致，以后只按账本操作，不随意改。

### 6. 资金效率原则（2026-11-15 定）

- **目的**：提高收益，最大利用资金周转，把复杂事情简单化。
- **区间**：合理确定将来一年的最高及最低点波动区间（52周高×1.05~1.10 定顶、52周低定底），作为布节点的范围，不多布。节点铺到一年内到不了的价格，等于把资金摊薄在不会交易的档位上，每档股数变少、收益被摊薄。
- **现金**：留足从现价跌到最低点的资金。现金储备 = 现价下方所有节点（股数 × 节点价）之和；如果超过可用现金，缩减每档股数，不跳节点。余钱分摊到各节点，提高资金效率。
- **账本定死**：按目前价格位置明确建仓数量及每个节点的数量，写进账本；**以后一年都按这个账本操作**，不盘中改、不随意改。价格跌破区间或涨破区间时重建账本。
- **兜底**：15% 保险金不动，是价格跌破区间时的最后兜底。

## 建仓步骤

1. **取数**：现价（最新收盘）、52 周高低点（前复权日线）、额度（每只 = 总额度 / 只数）。
2. **定区间与锚**：网格顶 = 52 周高 × 1.10（取整到 0.5 或 1.0），网格底 = 52 周低附近取整；锚 = 区间中点附近整数。核对：现价必须在区间内，否则区间错了，重定。
3. **算分位与首笔**：分位 = (现价 - 52周低) / (52周高 - 52周低)；首笔比例 = 40% - 25% × 分位；首笔金额 = 额度 × 首笔比例。
4. **配股数（金字塔）**：按 local-a-ledger 的方法，自现价上方第一可卖档起逐档向上至区间高点，低位多、高位少；每档卖出金额 ≥5000 元；仓位小铺不满时密度稀疏（跳档），但范围必须到（尤其最高档，保覆盖）。
5. **校验（三项硬门槛，缺一不可）**：
   - 覆盖 = 最高计划卖价 / 现价 ≥ 1.21。
   - 一板占比 = 涨一板（现价 × 1.10）卖出的股数 / 总股数 ≤ 50%（小仓位 50% 可接受，见 local-a-ledger 的 A2 先例）。
   - 每档卖出金额 ≥5000 元。
   - 校验不过，重配，不得交付。
6. **写账本**：按 local-a-ledger 的格式写《A线网格节点账本.md》，首笔分布即账本持仓分布；备份旧账本。
7. **Day 1 执行**：开盘市价买入首笔股数，按账本节点分配；买入后每档挂卖单（节点价 × 1.02）；成交后按总纲补挂（卖了补买、买了补卖）。
8. **回测验证（可选但推荐）**：用新浪 1 分钟数据跑 5 个交易日，确认三只第一天都有底仓、机制跑通；样本短，只看机制，不评估胜率。

## 坑（别再犯）

- **首笔挂单等回调**：市价上涨时买单不成交，Day 1 零持仓，违背“涨有股票”。首笔必须 Day 1 市价买入。
- **拿“一板 5 手”当硬门槛**：5 手是历史最高点的极端情况，分位高时一板可卖不足 5 手是正常的，按分位定仓才是现实。
- **用脱节的旧区间建仓**：区间必须按当前市价与 52 周高低点重定，市价不在区间内就是错的。
- **高位空仓等待**：高位不是空仓的理由，减数量就可以解决；底仓不能为零。
- **把首笔比例当固定值**：首笔不是固定的 35%，是按分位算出来的（15%~40%）；分位变了，首笔就变。
