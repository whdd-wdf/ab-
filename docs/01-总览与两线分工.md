# 01 总览与两线分工

## 系统一句话

一半是牛市思维（买趋势，做 T+0 影子训练，暂不实操），一半是平市或熊市思维（平摊成本、跑赢大盘、最后靠股息获利）；两半按市况互补，仓位与台账严格隔离。

## 两线分工

> 左右与长短口径（2026-10-26 用户确认）：**A 线左侧操作，不怕套、不怕亏，长线；B 线右侧操作，怕套、怕亏，短线。**

### A 线：逆向网格（平市 / 熊市思维）

- 和主力反着做：主力砸盘时买，主力拉高时卖，不跟风，不赌方向，赚波动的钱。
- 最坏情况靠股息回血，不死扛；网格品种不设硬止损，浮亏是常态，不作为行动信号。
- 八字诀：**涨有股票，跌有钞票**——上涨时卖到目标仓位即停、不卖穿；下跌时手里始终有现金、不提前打光子弹。
- 详见 [02 A 线逆向网格](02-A线逆向网格.md)。

### B 线：半日线（牛市思维）

- 大盘安全时，优选上涨趋势成立、基本面安全的股票；每天 14:30 筛选逻辑成立的股票补充 B 线。
- 买入后若趋势没有了，买入逻辑就不成立，考虑脱手，否则会被套。
- 交易原则：**买要考虑周全，卖要干脆**——买之前把大盘、趋势、基本面、价格上限、额度都想全；卖的信号一到就干脆执行，不拖、不幻想它自己回来。
- 详见 [03 B 线半日线](03-B线半日线.md)。

### T+0 影子训练（不下单、不算实盘成绩）

- 只针对 002475 做影子训练：趋势判断 + 决策后剩余时段涨跌幅预测为核心，快慢与反应速度为次要，依据是当日价量与近几日成交。
- 出场原则：趋势对时尾盘未闭环必须回补、不动底仓；趋势证伪时及时回补纠错。
- 时效铁律：信号拖久即无效；单信号确认延迟超 5 分钟要在日汇总中单独标注。
- 推进顺序：先实跑、修问题、跑稳再按就绪门槛检验，达标前不提实盘、不说成实盘成绩。
- 就绪门槛（提案，未达标）：影子闭环 ≥30 笔且胜率 ≥60%、盈亏比 ≥0.6、扣费后均笔净 >0、预测 AUC（走前）≥0.60、端到端延迟 P95 ≤5 分钟、连续 2 周同达标，才提请实盘。
- 详见 [05 操作时间线与大事记](05-操作时间线与大事记.md) 与 [07 风险与待办](07-风险与待办.md)。

## 共同纪律

- 模拟盘授权仅限虚拟资金，绝不跨入实盘；所有模拟盘操作第一时间通知。
- 成交价以当日成交记录为准，委托价 ≠ 成交价；未确认前台账写“委托中”，绝不编造成交。
- 行情走后台数据源，浏览器只用于下单；单任务窗口不超 3 个，尽量不刷新；登录态失效立即停止，不空转重试。
- 买入决策通用规则：买入理由不考虑前面持仓和盈亏，只当建仓评估；不以卖出价、亏损额作为买入与否或买入价的锚。
- 选股与行情必须用当日实时数据，拿不到就明确标注，不用昨天或更早的数据充数。
